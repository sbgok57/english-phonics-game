## 🌟 Game Highlights & Educational Architecture

### 1. 🔊 Dynamic Pure Phonics Audio Engine
- **Pure Phonemes ONLY**: All letters trigger pure phonetic acoustic sounds (e.g., short vowel `/æ/`, stop `/t/`, sibilant `/s/`) and **never** their letter names (*"ay"*, *"bee"*, *"cee"*).
- **Procedural Formant Synthesis**: Uses Web Audio API formant filters (F1/F2 resonant synthesis for vowels, burst transients for plosives, and shaped sibilance for fricatives), ensuring 100% offline reliability without missing asset files.
- **Voiceover Companion**: Friendly voice instructions and praise from **Astro the Tiger** guide the child through each learning activity.

---

### 2. 🎮 Interactive Stages & Minigames

| Stage | Name | Gameplay & Learning Mechanics |
| :--- | :--- | :--- |
| **Hub** | **🌴 Space-Jungle Platformer** | 2D exploration hub where kids control Astro the Space Tiger, run, jump on mushroom trampolines, collect phoneme gems, and jump into giant glowing stage portals. |
| **Stage 1** | **🍎 Phonics Sound Bubbles** | Floating physics bubbles containing lowercase letters bob around an animated central cartoon item (Apple, Sun, Turtle, Cat, Bus, etc.). Tapping plays the pure phoneme. Dragging the matching letter bubble into the target nest triggers star celebrations! |
| **Stage 2** | **✏️ Guided Letter Tracing** | Cosmic glowing slate displaying dashed outlines of lowercase letters. An animated guiding star with hand cues leads the child along the correct stroke path. Successful strokes illuminate with glowing crystal green and sparkle trails. |
| **Stage 3** | **⚙️ CVC Blending Factory** | Steampunk Space-Jungle conveyor belt mechanism. Letter blocks (`c`, `a`, `t`) arrive on the belt, sounding out pure phonemes sequentially (`/k/`... `/æ/`... `/t/`). Pulling the golden lever crushes/blends them in the chamber, loudly announcing the blended word (`CAT!`) and popping out an illustrated picture badge! |
| **Stage 4** | **👽 Sight Word Alien Popups** | Friendly animated aliens pop out of moon craters holding signs with high-frequency sight words (*the, is, my, and, you, see, we, like, can, go*). Prompt voice says *"Find: THE!"*. Tapping the correct alien triggers star explosions and happy dances; incorrect taps gently wobble down with a soft boing. |

## 🚀 How to Play

1. Open `index.html` in any modern web browser (or serve via any local web server, e.g. `npx serve .` or `python3 -m http.server`).
2. Tap **START ADVENTURE! 🚀** on the title screen to enable sound.
3. Use on-screen buttons or arrow keys to explore the platformer world, or use the top stage dock to jump directly into any minigame stage!
